# Наш данський

Невеликий приватний блокнот для друзів, які разом вивчають данську. Це не навчальна платформа для різних шкіл і груп: сайт допомагає нам зберігати власні правила, слова, пояснення й приклади з занять.

## Призначення

- **Правила:** коротка картка з назвою та описом; усередині — наше пояснення, як правило працює на практиці, приклади, винятки й нотатки.
- **Словник:** данське слово або вираз, переклад, короткий опис, контекст і приклади.
- **Схожі слова:** окремі картки діляться на два типи — схожі написанням/звучанням і близькі за значенням. Картка містить заголовок, тему, короткий опис і кілька слів із перекладом, конструкціями та прикладами. Старі групи за міткою переносяться до типу «схожі за формою».
- **Редактор:** український інтерфейс за замовчуванням, перемикач англійської мови. Мова інтерфейсу не змінює і не перекладає текст записів.
- **Форматування:** напівжирний, курсив, підкреслення, колір тексту, маркерне виділення, списки, заголовки й блоки-помітки «Увага», «Важливо», «Цікаво». Власні типи поміток можна додати й повторно використовувати; для них задаються назва, значок, колір тла й акцент.
- **Анімації:** картки, переходи між розділами й відкриття редактора з'являються плавно. Під час перестановки частина підхоплюється курсором, а сусідні частини анімовано розсуваються за місцем-підказкою. Параметр системи `prefers-reduced-motion` вимикає рух для тих, кому так зручніше.

## Робоча концепція

Правила й групи схожих слів показуються короткими картками. Повна інформація відкривається окремо, щоб довгі нотатки не захаращували списки. У редакторі текст можна складати з форматованих частин і переставляти їх угору чи вниз. Ручки та інші елементи керування потрібні лише під час редагування. Під час збереження частини зливаються в один звичайний HTML-текст у правильному порядку; координати, розміри й масив окремих блоків не зберігаються. Старі записи автоматично розкладаються на частини для редагування.

## Технології та структура

- `public/study.html` — сторінка блокнота (HTML, CSS і логіка записів).
- `public/canvas-editor.js` — редактор форматованого потоку: частини можна перетягувати вертикально й упорядковувати перед збереженням у звичайний текст.
- `public/index.html` — основна сторінка старого сайту з переходом до блокнота.
- `public/admin.html`, `public/chat.html`, `public/viewer.html` — інші сторінки попереднього сайту.
- `src/worker.js` — Cloudflare Worker із чинним API та авторизацією.
- `schema.sql` — схема Cloudflare D1.
- `wrangler.toml` — конфігурація Cloudflare Worker, D1 та R2.
- `preview-server.cjs` — мінімальний локальний сервер для перегляду статичних сторінок.

## Дані та спільний доступ

Навчальний блокнот наразі є локальним прототипом. Записи зберігаються у `localStorage` поточного браузера під ключами `danskPersonalWords`, `danskPersonalRules`, `danskCustomBlocks`, `danskSimilarCards` і `danskUiLanguage`. Через це учасники ще не бачать спільних змін. Наступний крок для спільної роботи — під'єднати блокнот до наявного Worker та D1, не створюючи окремий проєкт чи нову платформу. Дані записів мають лишатися власним вмістом друзів; мову інтерфейсу можна зберігати окремо для кожного учасника.

## Локальний перегляд

З кореня репозиторію запустити:

```sh
node preview-server.cjs
```

Потім відкрити <http://127.0.0.1:4173/study.html>. Локальний сервер віддає `public/` і не під'єднує API чи спільну базу.

## Початкові приклади

Демо-словник містить `beslutte`, `bekymre sig` і `beskytte` як схожі за написанням, але різні за значенням слова. Це приклади для перегляду структури; їх можна редагувати або видалити. Демо-правила теж показують можливий формат власних нотаток, а не є загальними курсами сайту.
