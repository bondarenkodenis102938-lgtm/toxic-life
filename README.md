# Наша данська — приватний спільний блокнот

Нова версія приватного навчального сайту для власника та запрошених друзів. Реалізація V2 ведеться в окремій гілці `v2-foundation`; стара версія в `main` залишається недоторканою, доки нову не буде перевірено.

## Призначення

- **Словник:** данське слово або вираз, переклад, коротке пояснення, типове вживання, приклади та розширена нотатка.
- **Правила:** граматичні записи з коротким описом і форматованим вмістом.
- **Схожі слова:** дві категорії — схожі за формою/звучанням та близькі за значенням/вживанням. Картка містить кілька слів. Слова зберігаються окремо й можуть повторно використовуватися в різних картках.
- **Редактор:** вертикальні текстові частини, форматування, блоки-помітки й перестановка частин. Під час збереження вони об'єднуються в один форматований документ; координати та розміри не є частиною даних.
- **Спільна робота:** усі зміни зберігаються на сервері в D1, а не в локальному сховищі браузера.

## Ролі та доступ

Реєстрація відкрита не буде. Нові учасники приєднуються лише за запрошенням.

- **Owner (головний адміністратор):** повний доступ до матеріалів, керування учасниками й створення запрошень.
- **Co-host:** може створювати, редагувати й видаляти навчальні матеріали, але не може запрошувати/видаляти учасників, змінювати ролі чи системні налаштування.
- **Перший Owner:** створюється одноразовим налаштуванням із секретом середовища. Паролі зберігаються лише як криптографічні хеші; сесії — у базі як хеші випадкових токенів із захищеною HttpOnly cookie.

## Технології

- HTML, CSS і JavaScript у `public/`.
- Cloudflare Worker у `src/worker-v2.js` — API, автентифікація та перевірка ролей.
- Cloudflare D1 — облікові записи, сесії, запрошення, слова, правила, картки та журнал змін.
- `migrations/` — версійовані SQL-міграції.
- `preview-server.cjs` — лише статичний локальний перегляд; він не замінює Worker і не підключає D1.

## Структура даних V2

`migrations/0001_initial.sql` створює:
- `users`, `sessions`, `invitations` — закритий доступ;
- `words` — канонічний словник;
- `rules` — граматичні нотатки;
- `similar_cards` і `similar_card_words` — групи зі зв'язками на словникові слова;
- `custom_callouts` — власні типи блоків-поміток;
- `audit_log` — хто й коли виконав важливу дію.

## Створення нової D1 бази

Після підготовки Worker потрібно створити окрему базу, не використовуючи стару:

```sh
npx wrangler d1 create nasha-danska-v2
```

Потім підставити отриманий `database_id` у `wrangler.toml` і застосувати міграції:

```sh
npx wrangler d1 migrations apply nasha-danska-v2 --remote
npx wrangler secret put BOOTSTRAP_SECRET
npx wrangler deploy
```

Для `BOOTSTRAP_SECRET` введіть довгий випадковий секрет у запиті Wrangler. Не надсилайте його в чат і не додавайте до Git. Після розгортання відкрийте адресу Worker: якщо Owner ще не створений, сайт покаже сторінку `/setup`. Після створення головного акаунта нові учасники додаються з розділу «Учасники».

Не запускайте міграцію, доки в `wrangler.toml` лишається нульовий placeholder ID.
